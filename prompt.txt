# 34. MONGODB TRANSACTION RULES

All money-moving operations must use MongoDB transactions.

For example:

```typescript
const session = await mongoose.startSession();

try {
  await session.withTransaction(async () => {
    // create transaction
    // create ledger entries
    // update account balances
    // create audit event
  });
} finally {
  await session.endSession();
}
```

Never update financial state outside transactional protection.
